# Academic Projects – Andrea Medori

Collection of university projects developed during my studies in Biomedical Engineering at **Università Campus Bio-Medico di Roma**.
Many projects were carried out as group work with fellow students; each folder contains its own README with details.

## Projects

| Project | Course | Topics | Period |
|---|---|---|---|
| [Retinal Disease Analysis on ODIR](Digital_Signal_and_Image_Processing/) | Digital Signal and Image Processing | Image processing, feature extraction (colour, GLCM), statistical tests, CNN, nested cross-validation | Jan–Feb 2025 |
| [Teleoperated Mobile Robot – Odometry & EKF](Mechatronics_Mobile_Robot/) | Mechatronics (group) | Embedded C (PIC), I²C encoders, Bluetooth, MATLAB GUI, odometry, Extended Kalman Filter | Nov 2024–Jun 2025 |
| [4-DOF LEGO EV3 Manipulator – Kinematics & Redundancy](Robotics_EV3_Manipulator/) | Industrial and Medical Robotics | DH, forward/inverse kinematics (CLIK), trajectory planning, redundancy resolution, dynamic model, LEGO EV3 (Python) | Mar–Jun 2025 |

| [ICD-10 Chapter Prediction](Machine_Learning_ICD10_Chapter_Prediction/) | Machine Learning and Big Data Analytics (group) | Clinical tabular data, feature engineering, statistical feature selection, LR/SVM/RF/XGBoost, nested CV, ablation study | May–Jul 2026 |
| [Hand of Hope – Clinical Investigation Protocol](Rehabilitation_HandOfHope_Clinical_Protocol/) | Rehabilitation Bioengineering (group, with physiotherapists) | EMG-driven hand exoskeleton, post-stroke rehabilitation, MDR clinical protocol, endpoints (FMA-UE, ARAT…), statistical analysis plan | Jan 2026 |
